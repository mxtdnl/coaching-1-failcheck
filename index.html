How status is calculated

Each item is complete (full marks) or incomplete (0). Blank cells are not yet marked and count as no loss. London: the two workshops form one -mark component: completing either secures it; it is lost only when both are 0. Boston: each workshop is worth marks and counts separately; Workshop is worth 0 and is ignored. A pass requires %, so a student fails once more than marks are lost.
